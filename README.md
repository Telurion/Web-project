# CIGEMS - For the lovers of gems

CIGEMS is an interactive web project where you have:

- Home page with our best sellers
- Find your gems, a wheel to determine your gem if you enter your birthday + postits with the short description of the gems
- A page product with all the gems
- An about us page, with a quick presentation of the participants of the project + map with a pin on a fictional adress of our shop
- You can sign up/login, it will remember you
- You can also add the articles into a cart, where you can check it on a side bar

## Technologies used

- HTML
- CSS
- JAVASCRIPT
- EXTERNAL API

## Precisions

For the part with signup/login, we used part of codes from the internet.

We use [Leaflet](https://leafletjs.com/) to display a zoomable map centered on Villejuif, with a pin to mark the fictional CIGEMS store.
